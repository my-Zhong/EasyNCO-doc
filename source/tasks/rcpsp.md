# Resource-Constrained Project Scheduling Problem

## Introduction
RCPSP is a classical model in project scheduling, where tasks are subject to precedence constraints and limited resources. The goal is to schedule the project while satisfying both resource limitations and task dependencies, typically to optimize the project duration.

## Problem Description
- Task: There are n tasks. Each task consumes a certain amount of resources during its execution.
- Resources: There are R types of resources, each with a fixed total availability. 
- Constraints: Tasks are subject to precedence constraints (e.g., task B cannot start before task A finishes). Resources must be used within their fixed limits.
- Objective: Minimize the project makespan (total project duration).
